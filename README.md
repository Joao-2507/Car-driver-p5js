## 📖 Sobre o projeto

**CAR DRIVER** é um jogo 2D desenvolvido utilizando
JavaScript e a biblioteca p5.js.

O jogador controla um carro que se movimenta
horizontalmente pela pista, buscando desviar de
obstáculos que surgem em posições aleatórias.

O objetivo é sobreviver aos obstáculos durante 30 segundos.

Esse jogo foi desenvolvido como um projeto da 3ª unidade para a matéria de Lógica de Programação do curso de Engenharia de Computação.

## 🎮 Controles

| Tecla | Ação |
|-------|------|
| ⬅️ | Mover para a esquerda |
| ➡️ | Mover para a direita |

## ⚙️ Funcionalidades

- Menu principal interativo.
- Tela de instruções e créditos.
- Movimentação horizontal do veículo.
- Geração aleatória de obstáculos.
- Aumento progressivo da velocidade dos obstáculos.
- Cronômetro de sobrevivência.
- Tela de vitória ao completar 30 segundos.

## 🛠️ Tecnologias utilizadas

- **JavaScript:** lógica e funcionalidades do jogo.
- **p5.js:** renderização gráfica e interatividade.
- **HTML5:** estrutura da aplicação.
- **CSS3:** configuração visual da página.

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra o projeto em um servidor web local.
3. Acesse o arquivo `index.html` pelo navegador.
4. Selecione "Jogar" para iniciar.

Também é possível acessar o projeto diretamente
pelo editor online do p5.js:

[**Acessar CAR DRIVER**](https://editor.p5js.org/joao.salustio/sketches/jNd5lJ4kf)
